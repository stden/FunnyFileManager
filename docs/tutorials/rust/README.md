# Rust на практике: разработка FFM

Учебник рассчитан на разработчика, который знает переменные, функции и
коллекции, но хочет писать надёжный Rust в реальном приложении.
Каждая глава объясняет решение, показывает пример и предлагает упражнение.
Примеры с собственными типами — самостоятельные учебные фрагменты;
точные интерфейсы FFM смотрите в указанных исходниках.

| Глава                                                        | Что вы научитесь делать                                                |
| ------------------------------------------------------------ | ---------------------------------------------------------------------- |
| [1. Типы и состояния](01-types.md)                           | Моделировать состояния через enum, проверять значения через newtype    |
| [2. Владение и ошибки](02-ownership-errors.md)               | Выбирать заимствования, проектировать ошибки и границы модулей         |
| [3. Эффекты и производительность](03-effects-performance.md) | Выносить I/O из UI, обрабатывать устаревшие ответы, измерять сложность |
| [4. Тестирование и рабочий процесс](04-testing.md)           | Разрабатывать через поведение, проверять TUI и конфигурацию            |

Читайте по порядку. Затем выполните итоговую работу: спроектируйте небольшую
панель со списком подключений, обновлением в фоне и сохранением настроек.
Используйте тестовый адаптер вместо настоящего сервера.

Объяснения здесь помогают понять решения. Обязательные требования находятся в
[AGENTS_FULL.md](../../../AGENTS_FULL.md), а краткий справочник —

репозитория: функции небольшие, состояние типизировано, ошибки наблюдаемы.

## Как заниматься

1. Прочитайте главу и объясните своими словами, какой дефект предотвращает тип.
2. Наберите пример и измените его: ошибка компиляции часто показывает границу модели.
3. Найдите соответствующее решение в FFM.
4. Напишите тест упражнения до реализации.
5. Проверьте код командами из последней главы.

Не переносите учебные типы в проект автоматически. Сначала ищите уже существующий
тип: `RemotePath`, `FileSize`, `PanelSide`, `UnixMode` и другие.
